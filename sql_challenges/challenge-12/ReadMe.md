# SQL Challenge 12 – KPI Dashboards

## Problem

The objective of this challenge is to build business-oriented metrics using SQL queries and present information that can be used to evaluate team performance and project progress.

## Schema

The challenge uses the tasks table enriched with additional analytics fields such as:

* priority
* due_date
* completed_at
* tags

These attributes allow more advanced KPI calculations and reporting.

## Approach

1. Analyze available task information.
2. Define meaningful KPIs.
3. Create SQL queries to calculate each metric.
4. Validate the results.
5. Present metrics in a dashboard-friendly format.

## Expected Result

The final solution should provide metrics that help evaluate workload, completion rates, overdue tasks, team productivity, and project health.
